# Paper

LaTeX source (acmart `acmsmall`), compiled in Overleaf: upload this folder, main file `main.tex`.

- `sections/` one file per section (layout: `project/PAPER-STRUCTURE.md`, D13).
- `figures/` TikZ figures.
- `generated/` written by scripts in `experiments/`; never edit by hand. Every number in the paper comes from there.
- `bibfile.bib` only verified entries.
- `\todo{...}` marks missing text, numbers or citations; none may remain at submission.

If you edit in Overleaf, copy the changed `.tex` files back here before Claude edits them.
