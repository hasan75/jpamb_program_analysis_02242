\section{Implementation}
\label{sec:implementation}
The pipeline is written in Python on top of the JPAMB harness, which reads
bytecode decompiled to JSON by \texttt{jvm2json}; all Java is compiled and run
in the benchmark's Docker image.

\paragraph{Analyzers and guide}
The three analyzers are one abstract interpreter, parameterized by the integer
domain and by whether branches refine, and exposed as three JPAMB analyzer
programs, so the standard \texttt{jpamb analyse} command scores each of them.
The experiments call the same prediction function directly, without starting
one analyzer process per method. The guide is
the interval configuration, run once per method with a second entry point that
exports, for every instruction, the abstract state before it, its source line,
and the uncertain instructions (\cref{sec:sites}). The line table in
\texttt{jvm2json}'s output is indexed by instruction, not by byte offset, so
states are mapped to lines through instruction indices.

\paragraph{Site finder and rewriter}
Sites are found on the Java source with a tree-sitter parser. The finder
checks the shared precondition syntactically, resolving each name by scope, and
skips methods that tree-sitter cannot parse completely, so that a rewrite never
drops source text. A variant is produced by replacing the byte range of one
syntax node with the rewritten text, in a copy of the class's source file.

\paragraph{Validation and analysis}
For each method, a small Java harness loads the original classes and each
variant in its own class loader inside one long-running container, runs every
synthesized input on every version, and prints outcome and return value; a JVM
that hits the time limit is restarted. Compiled variants are decompiled, and each
analyzer is run on every original method and every valid variant once, since
an outcome set depends only on the analyzer and the method version. The
strategies' orders are then replayed against these outcome sets for every seed
and budget, which makes the experiment cheap to repeat. Every number and table
in the evaluation is generated by a script from the stored results.\footnote{The
analyzers are in \texttt{solutions/static}, the site finder, rules, selection
and validation in \texttt{solutions/metamorphic}, and the experiment scripts in
\texttt{experiments/} of the project repository.}
